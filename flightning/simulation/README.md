# Flightning Simulation

This subpackage contains additional simulation tools for quadrotor simulation.

| Module                          | Description                                    |
|---------------------------------|------------------------------------------------|
| model_body_drag                 | Air drag model based on simple quadratic model |
| model_rotor_simple_augmentation | Augmentation file based air drag model         |

| Directory          | Description                                          |
|--------------------|------------------------------------------------------|
| params             | yaml files describing parameters for model_body_drag |
| augmentation_files | yaml files describing augmentation configs           |
